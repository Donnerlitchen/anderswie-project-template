# Übergreifende fachliche Grundsätze

**Stand:** 2026-10-31. Hier stehen **nur** Grundsätze, die für alle Module gelten. Modulanforderungen
stehen je in `docs/Spezifikation-<Modul>.md` — eine Regel hat genau einen Ort.

## Regelverzeichnis

| ID | Grundsatz |
|---|---|
| GR-01 | **Wahrheit:** Keine erfundenen Ergebnisse. Unbeobachtetes bleibt leer, nie geschätzt. |
| GR-02 | **Quellentrennung:** Datenquellen bleiben getrennt; Herkunft ist im Ergebnis erkennbar. |

Die Anwendung meldet die **Regelwerksversion** (z. B. `rules-1.0`), nicht eine Einzelregel-Nummer —
sonst wird jede Umnummerierung zu einer Code-Änderung.
